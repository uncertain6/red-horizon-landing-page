# Red Horizon

A concept site for a Mars space-tourism brand. No framework, just HTML and CSS, built to look and feel like something SpaceX would actually ship — dark, cinematic, data-driven.

![Red Horizon hero](./preview.png)

## Stack
Plain HTML + CSS, split across four files:
- `general.css` — tokens, resets, shared typography
- `header.css` — nav
- `main.css` — hero, mission, features, pricing
- `footer.css` — footer

Fonts: Orbitron (headings), Exo 2 (body), both from Google Fonts.

## Sections
- **Hero** — layered gradient + clip-path light beam
- **Mission** — quiet manifesto copy, stats row
- **Features** — three journey tiers (Orbiter / Pioneer / Colonist)
- **Pricing** — flight-manifest style, not pricing cards
- **Footer** — logo, nav, copyright, done

## Running it
Just open `index.html`. No build step, no dependencies.

## Status
Personal project, still evolving section by section.
